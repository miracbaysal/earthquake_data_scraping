### TR
Bu proje kandilli rasathanesi deprem verilerini çekerek bir veritabanına yazdırır. Daha sonra d3.js kullanarak bu verileri harita üzerinde görselleştirir. Vercel yardımıyla görselleştirilen veriler websitesinde yayınlanır.
[Websiteyi ziyaret et](https://earthquake-data-scraping.vercel.app/)
- Kullanılan Teknolojiler:
  * Python
  * Airflow
  * Dbeaver(Postgres)
  * Docker
  * Github
  * Vercel
 
### EN
This project extracts earthquake data from the Kandilli Rasathanesi and load it into a database. It then visualizes this data on a map using d3.js. The visualized data, using Vercel, is published on the website. 
[Visit the website](https://earthquake-data-scraping.vercel.app/)
- Technologies Used:
  * Python
  * Airflow
  * Dbeaver(Postgres)
  * Docker
  * Github
  * Vercel
